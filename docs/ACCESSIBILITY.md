# Accessibility

All four Phase 4 workflows use the shared SightLine colors, typography, spacing, surfaces, focus and reduced-motion rules. Navigation, headings, main landmark, skip link, page titles and current-page state are semantic. Errors use alerts; completion/progress uses polite live regions. Provider and fallback status are textual.

Visual Assist and Screen Lens pair image overlays with an object list, confidence and source coordinates. A checkbox toggles overlays. Clipboard read is an explicit button and Ctrl+V is supported. Clear image returns focus to file selection. No inference claim relies only on color.

Privacy Shield has a complete keyboard alternative to dragging: labeled left/top/width/height fields, effect selector, Add, Remove, Undo and Clear controls. Original and redacted canvases have accessible descriptions; the selected-region list includes coordinates and effects. Exports are disabled until an image has a region.

Performance Lab has labeled bounded numeric inputs, busy/completion state and semantic tables with captions/headers. Missing memory and FPS measurements are explained in text.

Local checks: keyboard-driven sample analysis, clipboard import, manual region entry and export; desktop rendering and compact viewport inspection. Narrator/NVDA, OS high contrast, comprehensive contrast and 200–400% zoom audits remain required. This is not WCAG certification.
