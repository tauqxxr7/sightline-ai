# Measured CPU benchmarks

Performance Lab and `python -m scripts.benchmark --samples 10 --warmups 2` execute the same runner. Each request creates a fresh CPU-only ORT session, runs the NASA fixture once to measure session initialization and cold pipeline stages, performs 1–5 excluded warmups, then measures 3–30 samples. Every inference/postprocessing call uses the real pinned YOLOX model. No fake timing or QNN comparison is generated.

Stage measurements use perf_counter: model initialization (including verification/load), image decoding/preprocessing, synchronous inference, postprocessing and total local pipeline. Warm sessions are checked for reuse. UI rendering, HTTP transfer and artifact serialization are excluded. A fresh session is not a cold process or cold OS cache.

JSON records all cold, warmup and measured timings, counts, model version/hash, input hash/dimensions, precision, threading settings, environment, active/requested/available providers and fallback. Summaries include mean, median, nearest-rank p95, population standard deviation, min and max for measured runs only. At ten samples, nearest-rank p95 is the maximum; use more runs for a better tail estimate.

Artifacts are saved under `benchmarks/results/<random-id>.json` and `.csv`. CPU baseline only. No video FPS or native/process memory measurement is available; these fields are null with reasons. A single repeated image does not measure accuracy, realistic workload throughput, thermals or battery life. Hardware state and competing processes affect values.

The loopback endpoint accepts only bounded sample/warmup counts. It shares the inference concurrency lock. A 120-second budget is checked between native calls; a native call already in progress cannot be cancelled by the browser. Leaving the view stops waiting but completed artifacts can still be written. Paths are generated by the server, not accepted from the browser. No input pixels, filenames or detections are persisted in reports.

Inference median 12.0321 ms, p95 17.8477 ms; fresh-session initialization 81.6536 ms. These observations are not guarantees. See the Phase 4 report and raw JSON/CSV for evidence.
